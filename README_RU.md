# ETN RAPIRA ONLINE — репозиторий для Bothost

## Файлы
- `server.py` — Flask API и выдача `web/index.html`.
- `bot.py` — Telegram-бот, который открывает Mini App.
- `web/index.html` — интерфейс сайта.
- `requirements.txt` — зависимости.
- `Procfile` — команда веб-сервера для платформ, поддерживающих Procfile.

## Настройка веб-сервиса
1. Подключите этот репозиторий к Bothost.
2. Для веб-сервиса используйте команду запуска `gunicorn --bind 0.0.0.0:$PORT server:app` (если панель просит команду). Если поддерживается Procfile, он уже содержит её.
3. Установите переменную `BOT_TOKEN` со значением токена от BotFather. Не записывайте токен в GitHub.
4. Для постоянной SQLite-базы задайте `ETN_DB_PATH=/app/data/etn.sqlite3` и убедитесь, что `/app/data` — постоянное хранилище на вашем тарифе. Если Bothost использует другой путь для persistent storage, укажите именно его.
5. После запуска проверьте `https://ВАШ-ДОМЕН/api/health`: ожидается JSON с `"ok": true`. Корень `/` должен отдавать сайт.

## Telegram-бот
Бот — отдельный долгоживущий процесс. Если Bothost позволяет создать отдельный worker/service, запустите в нём `python bot.py` и задайте `BOT_TOKEN` и `WEBAPP_URL` (публичный HTTPS URL сайта, который должен быть открыт внутри Telegram). Не запускайте второй экземпляр polling-бота с тем же токеном.

## Netlify
Текущая версия фронтенда использует относительные `/api/...` запросы. Чтобы Netlify-сайт обращался к серверу Bothost, настройте Netlify proxy/redirect для `/api/*` на адрес Bothost либо разверните сам фронтенд через Flask на Bothost. Если оставить фронтенд на Netlify без прокси, относительные API-запросы пойдут на Netlify, а не на Bothost.

## Проверки
- `GET /api/health` — проверка сервера.
- `GET /` — проверка выдачи интерфейса.
- API профиля и рейтинга требует валидный Telegram Mini App `initData`; открытие напрямую в браузере не является проверкой авторизации Telegram.

## Важно
Этот пакет — deploy-ready каркас, но не доказательство успешного развёртывания в аккаунте Bothost. Проверьте фактический persistent storage, запуск отдельного bot worker и настройку Netlify proxy в панели. Не добавляйте токены и реальные данные пользователей в публичный репозиторий.
